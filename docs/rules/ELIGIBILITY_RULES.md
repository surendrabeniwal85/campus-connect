# Eligibility rules (owner: Aliza)

Each rule gives PASS, FAIL or MISSING. MISSING means the student's data is not available yet. It is never shown as FAIL. There is no hidden score.

| Rule | Student value comes from | Passes when | Edge (confirm with TPO) |
|---|---|---|---|
| Minimum CGPA | Student service | CGPA >= minimum | equal passes |
| Maximum active backlogs | Student service | backlogs <= maximum | equal passes |
| Minimum Class 10 percent | Student service | percent >= minimum | equal passes |
| Minimum Class 12 percent | Student service | percent >= minimum | equal passes |
| Minimum attendance percent | Attendance service | percent >= minimum | equal passes |
| Allowed branches | Student service | branch is in the list | none |
| Passing year | Student service | year equals the drive year | none |
| Minimum ATS score (optional) | Resume service | score >= minimum | MISSING if no resume |

A failed rule gives a plain next action, for example: Attendance 68%, need 75%. Attend more classes.

Open questions for the TPO: the real minimum numbers for each company, and whether equal to the limit passes.
